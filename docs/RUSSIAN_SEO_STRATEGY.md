# 俄语市场 SEO 策略 — TZG Energy

> **核心洞察**：俄语市场（CIS 俄语区）有 Yandex + Google 两大搜索引擎并行，必须双管齐下。  
> Yandex 在俄罗斯占 40-50% 市场份额，但在 CIS 国家（哈萨克斯坦、白俄罗斯、乌兹别克斯坦）占据主导地位。  
> 我们的目标市场：俄罗斯、独联体国家、中东俄语客户。

---

## 一、双引擎策略概览

| 搜索引擎 | 俄语市场份额 | 主要市场 | 特点 |
|---|---|---|---|
| **Yandex** | 40-50%（俄罗斯）/ 60-80%（CIS）| 俄罗斯、哈萨克、白俄罗斯、乌兹别克 | 母语用户首选，对俄语内容理解更深 |
| **Google** | 50-60%（俄罗斯）/ 20-40%（CIS）| 全球通用、技术派用户 | 算法成熟，工具齐全 |
| **Mail.ru** | <5% | 俄罗斯 | 没必要单独优化（继承 Yandex） |

**结论**：必须同时优化 Yandex + Google，不要二选一。

---

## 二、Yandex 与 Google 的关键差异

| 维度 | Yandex | Google |
|---|---|---|
| **算法名称** | MatrixNet (机器学习) + YandexGPT Overviews | RankBrain + Gemini AI Overviews |
| **外链权重** | 中等（更看重内容和地理位置）| 极高（核心排名因素）|
| **内容质量** | **更看重原创、深度、专家性** | 看重 E-E-A-T（经验、专业、权威、可信）|
| **关键词密度** | 容忍度较高 | 严格（关键词堆砌会被惩罚）|
| **本地化** | 极重视（IP 地理位置、注册地、Yandex.Maps）| 同样重要但工具更多 |
| **图片 SEO** | `alt` 标签极重要 | 重要但非核心 |
| **CTR 影响** | 极大（标题/描述 CTR 是核心排名因素）| 中等 |
| **社交信号** | 看 VKontakte、Odnoklassniki | 看 Facebook、Twitter |
| **用户行为** | 重视跳出率、停留时间、Dwell time | 类似但权重略低 |
| **HTTPS** | 必需 | 必需 |

**对 TZG 的具体含义**：
1. **内容深度 > 外链数量**：每篇俄语博客 2000+ 字 + 真实数据 + 案例
2. **地理位置信号**：服务器 IP、内容里明确标注"поставка в РФ"、"сертификация ЕАЭС"
3. **CTR 优化**：俄语标题/描述要本地化、写得有吸引力
4. **VK 推广**：在 VKontakte 创建公司主页，引导用户互动

## 三、Yandex 工具栈（必须配置）

### 3.1 Yandex Webmaster（类似 Google Search Console）

**地址**：https://webmaster.yandex.com

**配置步骤**：
1. 添加 `tzgenergy.com` 域名
2. 验证所有权（DNS TXT 记录最稳定）
3. 设置目标地区：俄罗斯 + 哈萨克 + 白俄罗斯
4. 提交 sitemap：
   - `https://tzgenergy.com/sitemap.xml`（自动包含所有语种）
5. 检查"Индексирование"（索引）→ 等待 /ru 页面被收录
6. 设置监控关键词

**DNS 验证记录**（需在 Cloudflare 加）：

```
类型: TXT
名称: @
内容: yandex-verification: 你的验证码（Webmaster 界面会显示）
```

### 3.2 Yandex Metrica（类似 Google Analytics）

**地址**：https://metrika.yandex.com

**功能**：
- 详细用户行为（点击热图、会话录制）
- 转化追踪（询盘提交、WhatsApp 点击）
- 漏斗分析
- Webvisor（类似 Hotjar）

**集成步骤**（已在我们的代码中预留）：
1. 在 Metrica 创建 counter，拿到 ID（形如 `98765432`）
2. 设置 Vercel 环境变量：`NEXT_PUBLIC_YANDEX_METRICA_ID=98765432`
3. 部署（自动激活，已有 `<YandexMetrica />` 组件）

**关键追踪事件建议**（需要后续加）：

```javascript
// 询盘提交
ym(COUNTER_ID, 'reachGoal', 'INQUIRY_SUBMIT', { locale: 'ru' });
// WhatsApp 点击

// Datasheet 下载
ym(COUNTER_ID, 'reachGoal', 'DATASHEET_DOWNLOAD', { product: 'r10' });
```

### 4.3 内容本地化（不是翻译，是本地创作）

❌ **错误做法**：英文 → 谷歌翻译 → 俄语
✅ **正确做法**：
1. 英文写核心信息
2. 找**俄语母语写手**改写（不是翻译！）
3. 包含俄语用户关心的话题（气候、电网稳定性、ЕАЭС 认证等）

**话题本地化举例**：

| 英文话题 | 俄语本地化角度 |
|---|---|
| BESS for backup power | BESS для бесперебойного питания при отключениях（针对俄罗斯停电） |
| Cold weather battery | Морозостойкие аккумуляторы для Сибири（西伯利亚耐低温） |
